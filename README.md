# TorrServerManager

Трей-приложение для Windows, которое держит на домашнем ПК связку **TorrServer + Jackett**
и раздаёт плагины для **Lampa**, установленной как приложение на телевизоре LG (WebOS).

## Зачем это нужно

Lampa на WebOS сама по себе — только плеер-оболочка. Ей нужен источник торрентов
(TorrServer) и по желанию — расширенный поиск (Jackett/Torznab), а ещё плагины,
которые обычно грузятся с случайных GitHub-адресов и на практике часто недоступны
или медленные. TorrServerManager закрывает всё это на стороне ПК:

- держит TorrServer и Jackett запущенными, следит за состоянием, перезапускает при сбоях;
- обновляет TorrServer с проверкой SHA-256 и откатом, если новая версия не стартует;
- скачивает и кеширует Lampa-плагины локально и раздаёт их телевизору по LAN
  (Plugin Hub, порт 8095) — телевизору не нужен выход в интернет за каждым плагином;
- прокидывает логин/пароль RuTracker.org прямо в конфиг Jackett через API, без ручного
  захода в веб-панель Jackett;
- добавляет собственный плагин Smart TS (сериалы: сезоны/серии, предзагрузка).

Подробности по внутреннему устройству — в [CLAUDE.md](CLAUDE.md).

## Требования

- Windows, .NET 10 (см. [CLAUDE.md](CLAUDE.md) для команд сборки).
- ПК и телевизор — в одной локальной сети (Wi-Fi/LAN). Внешний доступ из интернета
  не предусмотрен и не нужен — всё общение только по LAN.
- **TorrServer.exe** должен быть один раз вручную положен в
  `%LocalAppData%\Programs\TorrServer\TorrServer.exe` — сам менеджер устанавливает
  TorrServer только когда бинарник уже на месте, а сам его с нуля не скачивает
  (`ServerController.StartAsync` иначе бросает `FileNotFoundException`). Дальнейшие
  обновления менеджер делает уже сам.
- **Jackett** нужно установить отдельно штатным инсталлятором Jackett — он ставит
  его как службу Windows (`Jackett`, автозапуск). Менеджер эту службу только
  запускает/останавливает/перезапускает (`sc.exe`, `Restart-Service`, оба требуют
  подтверждения UAC), но не устанавливает Jackett с нуля.

## Первоначальная настройка Lampa на телевизоре

1. На телевизоре: **Настройки → Расширения → Добавить плагин**.
2. Вписать адрес загрузчика вида `http://<LAN-IP-компьютера>:8095/lampa.js`.
   Текущий адрес виден в окне менеджера (поле «Для Lampa») или в панели
   Plugin Hub (`http://127.0.0.1:8095/` на самом ПК).
3. Больше ничего добавлять не нужно — загрузчик сам проставит Lampa адрес
   TorrServer и подключит включённые плагины из кеша.

### Важный нюанс: IP компьютера может смениться

Роутер (в текущей обстановке — от Cyta, Кипр) выдаёт ПК адрес по DHCP.
Даже с попыткой закрепления по MAC-адресу IP иногда меняется — тогда адрес
загрузчика на телевизоре перестаёт работать, и его приходится перевбивать
руками через **Настройки → Расширения** в Lampa.

Что можно сделать:
- Проверить в панели администратора роутера Cyta, что для MAC-адреса ПК
  действительно настроена **статическая DHCP-резервация** (не просто «попытка»
  через выданную аренду) — часто именно это и не срабатывает.
- Либо задать ПК статический IP вручную в настройках сетевого адаптера Windows,
  вне диапазона DHCP-пула роутера.
- Текущий актуальный адрес всегда можно посмотреть в окне менеджера — поле
  «Для Lampa» обновляется на лету (`ServerController.GetPreferredLanAddress`).

Пока это ручной шаг: сам механизм отслеживания смены IP и авто-обновления
адреса на телевизоре в проекте не реализован.

## Автозапуск

На этом ПК автозапуск сделан через ярлык в папке автозагрузки Windows
(`%AppData%\Microsoft\Windows\Start Menu\Programs\Startup\TorrServer.lnk`),
который запускает `TorrServerManager.exe --background` — окно не показывается,
приложение сразу уходит в трей (см. `Program.cs` / флаг `--background`).
