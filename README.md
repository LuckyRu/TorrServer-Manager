# TorrServerManager

Трей-приложение для Windows, которое держит на домашнем ПК связку **TorrServer + Jackett + FlareSolverr**
и раздаёт плагины для **Lampa**, установленной как приложение на телевизоре LG (WebOS).

## Зачем это нужно

Lampa на WebOS сама по себе — только плеер-оболочка. Ей нужен источник торрентов
(TorrServer) и по желанию — расширенный поиск (Jackett/Torznab), а ещё плагины,
которые обычно грузятся с случайных GitHub-адресов и на практике часто недоступны
или медленные. TorrServerManager закрывает всё это на стороне ПК:

- держит TorrServer, Jackett и FlareSolverr запущенными как обычные дочерние процессы, следит за
  состоянием, перезапускает при сбоях — без служб Windows и без UAC на каждый клик;
- supervisor проверяет процессы и HTTP API раз в 5 секунд: исчезнувший процесс запускается сразу,
  зависший API перезапускается после трёх неудачных проверок, а повторные ошибки получают
  экспоненциальную паузу до 5 минут. Ручная остановка отключает восстановление до следующего запуска;
- проверяет новые upstream-релизы TorrServer и сообщает создателю ПО, когда нужен rebase
  downstream-изменений и новая сборка;
- скачивает и кеширует Lampa-плагины локально и раздаёт их телевизору по LAN
  (Plugin Hub, порт 8095) — телевизору не нужен выход в интернет за каждым плагином;
- сам создаёт нужные правила файервола для LAN-доступа (см. ниже), чтобы после
  переустановки ничего не приходилось настраивать руками;
- добавляет собственный плагин Torrent Mod (поиск сразу по всем источникам Jackett,
  свой экран результатов, буферизация под длительность просмотра).

## Зачем создан Torrent Mod

Штатный торрент-экран Lampa слишком общий для домашней медиатеки: он не знает контекст
произведения из TMDB достаточно глубоко, смешивает фильмы и сериалы, не умеет надёжно отбирать
раздачи под конкретный сезон и эпизод и оставляет пользователю разбор технического мусора в
названиях. Для сериалов это особенно заметно: одна раздача может содержать весь сериал, сезон,
пак эпизодов или несколько сезонов сразу.

Torrent Mod — самостоятельный экран Lampa, который запускается из уже найденной карточки TMDB и
решает эту задачу как доменный поиск:

- параллельно ищет по всем настроенным источникам Jackett/Torznab и объединяет результаты;
- разбирает названия раздач: сезон, эпизоды, разрешение, кодек, HDR, контейнер, перевод,
  студию и субтитры;
- отбрасывает книги, игры, аудио, бонусы, чужие произведения и неподходящие сезоны ещё до
  попадания в рабочий список;
- оценивает кандидатов по соответствию, качеству и доступности — число сидов является важным
  фактором, потому что хорошая картинка без стабильной загрузки непригодна для просмотра;
- разделяет сценарии фильма и сериала: для сериала строится общий пул раздач всего произведения,
  а сезон и серия выбираются локально без повторного поиска;
- позволяет фильтровать результаты по качеству, типу перевода, студии и другим распознанным
  свойствам, сохраняя выбор пользователя между сеансами.

Плагин не заставляет пользователя вручную придумывать поисковый запрос: источником названия,
идентификатора и структуры сезонов остаётся TMDB. Если TMDB не дала корректный контекст, Torrent
Mod не подменяет его произвольным ручным поиском, который часто только увеличивает количество
ложных совпадений.

Для воспроизведения Torrent Mod использует обычный `Lampa.Player`, но отдаёт ему подготовленный
GST/HLS-поток TorrServer. Перед стартом плагин получает метаданные файла и список дорожек, после
чего плеер может показать доступные аудиодорожки и субтитры. Это позволяет выбирать перевод,
работать с несколькими дорожками одного файла и переносить тяжёлую работу с контейнерами и
кодеками на GStreamer, а не полагаться на возможности браузера телевизора.

Подробнее: [поиск, скоринг и буферизация](docs/system-design/torrent-mod-search-pipeline.md),
[доменная архитектура](docs/system-design/torrent-mod-domain-architecture.md) и
[устойчивость GStreamer-пайплайна](docs/system-design/gstreamer-pipeline-robustness.md).

Подробности по внутреннему устройству — в [CLAUDE.md](CLAUDE.md).

## Требования

- Windows, .NET 10, Node.js (для сборки `TorrentModPlugin.js` — см. [CLAUDE.md](CLAUDE.md) для
  команд сборки и подробностей).
- ПК и телевизор — в одной локальной сети (Wi-Fi/LAN). Внешний доступ из интернета
  не предусмотрен и не нужен — всё общение только по LAN.
- **TorrServer.exe** должен быть один раз вручную положен в
  `%LocalAppData%\Programs\TorrServer\TorrServer.exe` — сам менеджер устанавливает
  TorrServer только когда бинарник уже на месте, а сам его с нуля не скачивает
  (`ServerController.StartAsync` иначе бросает `FileNotFoundException`). Обновления
  патченного бинарника собираются из исходников.
- **Jackett** нужно один раз положить (portable-версия, без установки службы) в
  `%ProgramData%\Jackett\App\JackettConsole.exe` — либо взять собранный fork-артефакт из
  `publish\Jackett\App` после `scripts\build-all.ps1`. Дальше менеджер запускает его как обычный
  дочерний процесс (`-z --DataFolder … -p 9117 --NoUpdates`), без службы Windows и без UAC на
  старт/стоп/перезапуск. Схема source-release описана в
  [`docs/how-to/rebuild-patched-jackett.md`](docs/how-to/rebuild-patched-jackett.md).
- **FlareSolverr** нужно один раз распаковать в `%ProgramData%\FlareSolverr\flaresolverr\flaresolverr.exe`.
  Менеджер запускает официальный Windows x64-бинарник на `127.0.0.1:8191` перед Jackett и сам
  прописывает `FlareSolverrUrl` в `ServerConfig.json`. FlareSolverr нужен индексаторам, которые
  защищены Cloudflare или похожей антибот-проверкой; наружу порт `8191` не открывается. Версия
  показывается в карточке FlareSolverr, менеджер проверяет новые релизы GitHub раз в 6 часов и
  устанавливает их в фоне с проверкой SHA-256 и откатом при неудачном запуске.
- При первом запуске менеджер сам проверяет и, если нужно, создаёт правила Windows
  Firewall для LAN-доступа к TorrServer (`8090`) и Plugin Hub (`8095`) — это
  единственный момент, когда может появиться окно UAC (один раз). Самому Jackett
  правило не нужно: он слушает только `127.0.0.1`, TorrServerManager обращается к
  нему локально.
- **RuTracker.org** в Jackett настраивается вручную, через штатную веб-панель
  Jackett (кнопка «Открыть» в карточке Jackett или в трее). Раньше менеджер умел
  сам прописывать логин/пароль в конфиг индексатора через API, но RuTracker
  периодически требует капчу при входе — автоматически её не пройти, поэтому
  этот код убрали. Капча решается один раз руками прямо в панели Jackett.

## Первоначальная настройка Lampa на телевизоре

1. На телевизоре: **Настройки → Расширения → Добавить плагин**.
2. Вписать адрес загрузчика вида `http://<LAN-IP-компьютера>:8095/lampa.js`.
   В окне менеджера, в карточке «Плагины Lampa», этот адрес показан прямо под
   заголовком с кнопкой «Копировать» — можно скопировать и вставить на телевизоре,
   ничего не переписывая руками. Адрес пересчитывается на лету при каждом
   обновлении статуса, так что после смены IP просто откройте менеджер ещё раз.
3. Больше ничего добавлять не нужно — загрузчик сам проставит Lampa адрес
   TorrServer и подключит включённые плагины из кеша.

### Важный нюанс: IP компьютера может смениться

Роутер (в текущей обстановке — от Cyta, Кипр) выдаёт ПК адрес по DHCP.
Даже с попыткой закрепления по MAC-адресу IP иногда меняется — тогда адрес
загрузчика на телевизоре перестаёт работать, и его приходится перевбивать
руками через **Настройки → Расширения** в Lampa.

Что можно сделать:
- Проверить в панели администратора роутера Cyta, что для MAC-адреса ПК
  действительно настроена **статическая DHCP-резервация** (не просто «попытка»
  через выданную аренду) — часто именно это и не срабатывает.
- Либо задать ПК статический IP вручную в настройках сетевого адаптера Windows,
  вне диапазона DHCP-пула роутера.
- Текущий актуальный адрес всегда можно посмотреть в окне менеджера — и адрес
  TorrServer («Для Lampa»), и адрес загрузчика плагинов обновляются на лету
  (`ServerController.GetPreferredLanAddress`) и у обоих есть кнопка «Копировать».

Пока это ручной шаг: сам механизм отслеживания смены IP и авто-обновления
адреса на телевизоре в проекте не реализован.

## Автозапуск

На этом ПК автозапуск сделан через ярлык в папке автозагрузки Windows
(`%AppData%\Microsoft\Windows\Start Menu\Programs\Startup\TorrServer.lnk`),
который запускает `TorrServerManager.exe --background` — окно не показывается,
приложение сразу уходит в трей (см. `Program.cs` / флаг `--background`).

## Сборка и разработка

Полная сборка clean clone — одна команда:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-all.ps1
```

Она инициализирует субмодули `external\TorrServer` и `external\Jackett` из форков
`LuckyRu/TorrServer` и `LuckyRu/Jackett`, собирает закреплённые родительским репозиторием
downstream-коммиты и проверяет их upstream-теги (`MatriX.<upstream>-TorrentMod.<version>` для
TorrServer и `v<upstream>-JackettManager.<version>` для Jackett), затем подтверждает официальные
upstream-базы. Результат: `TorrServer.exe`, self-contained Jackett в `publish\Jackett\App\` и
`TorrServerManager.exe` вместе со встроенным Torrent Mod Plugin в `publish\`.
Требуются Windows, Git с доступом к субмодулям, .NET 10 SDK и Node.js; требуемую версию Go скрипт читает из
`external\TorrServer\server\go.mod`, найдёт на PATH или скачает в
игнорируемый `.tools\`.

После обычного `git clone` нужно выполнить `git submodule update --init --recursive` либо клонировать
репозиторий сразу с `--recurse-submodules`. Сборка не изменяет рабочее дерево субмодулей: исходники
TorrServer копируются во временный `.build\`, а downstream-изменения живут отдельными коммитами
веток `torrserver-manager` и `jackett-manager` соответствующих форков. Схема Jackett и порядок
выпуска описаны в [`docs/how-to/rebuild-patched-jackett.md`](docs/how-to/rebuild-patched-jackett.md).

Для отдельных изменений Manager см. [CLAUDE.md](CLAUDE.md) — команды `dotnet build` / `dotnet publish`,
архитектура компонентов (`ServerController`, `JackettController`, `UpdateService`,
`PluginHub`, встроенный `TorrentModPlugin.js`).

Более подробная документация — в [docs/](docs/README.md): пошаговые инструкции, архитектурные решения
(ADR) и разборы того, как устроены поиск/скоринг Torrent Mod и навигация Lampa.
