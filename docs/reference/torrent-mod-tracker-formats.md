# Трекеры, форматы раздач и порядок разбора

Справочник: что именно умеет разобрать Torrent Mod, в каком порядке и на каких трекерах.

Все проценты в этом документе — замеры на корпусе из **1780 живых заголовков**
(`Plugins/TorrentModPlugin/test/fixtures/live-multitracker.json`), снятых с настоящего Jackett этой
установки. Они описывают текущее поведение кода; при изменении разбора замеры надо переснять, а не
править числа руками. Замеры «до» перестройки и обоснование решений —
[`torrent-mod-search-architecture.md`](../system-design/torrent-mod-search-architecture.md).

Источник истины по коду: `search/rules/tracker-profiles.js` (реестр), `search/parse/` (разбор),
`search/gates/` (отсев), `search/rank/scoring.js` (ранжирование).

---

## 1. Порядок работы: что за чем включается

### 1.1 Приём раздачи в пул произведения

Выполняется один раз на каждую запись, пришедшую от индексатора.

| # | Шаг | Файл | Что делает |
|---|---|---|---|
| 1 | `profileFor(indexerId, name)` | `rules/tracker-profiles.js` | Находит профиль трекера по **id индексатора Jackett**. Неизвестный id → общий профиль |
| 2 | `mapTorrent` | `transport/search-backend.js` | Нормализует поля Jackett: `title`, `tracker`, `trackerId`, `size`, `seeders`, `leechers`, `publishedAt`, `magnet`/`link` |
| 3 | `parseRelease(title, profile)` | `parse/release-parsing.js` | Разбирает заголовок (см. §1.2) |
| 4 | гейт `record` | `transport/search-backend.js` | Есть magnet или link, парсер не бросил исключение |
| 5 | гейт `media-type` | `gates/search-gates.js` | Это видеорелиз, а не книга, игра, аудио или бонусные материалы |
| 6 | гейт `title` | `gates/search-gates.js` | Заголовок относится к этому произведению |
| 7 | `mergeReleases` | `shared/release-identity.js` | Схлопывание дублей по `title\|tracker\|size` |

Прошедшее попадает в `state.pool` — общий пул на всё произведение ([ADR-0005](../adr/0005-search-whole-season-once.md)).

### 1.2 Разбор заголовка — точный порядок

`parseRelease(title, profile)`:

1. **`stripByProfile`** — срезает то, что профиль трекера объявил техническим (см. §2.2). Всё
   дальнейшее работает уже по очищенной строке.
2. **`parseSignals`** — нумерация и тип релиза (см. §1.3).
3. **`extractVoiceTypes`** — тип перевода (см. §1.4).
4. `resolution` — `2160p|4k|uhd` → `2160p`, затем `1080p`, `720p`, `480p`. Первое совпадение.
5. `sourceType` — по убыванию приоритета: `BDRemux|Remux` → `Blu-ray|BDRip` → `WEB-DLRip` →
   `WEB-DL` → `WEBRip` → `HDTV` → `SDTV` → `DVDRip` → `HDRip` → `CAMRip|TS`.
6. `hdr` — `Dolby Vision|DV` → `DV`, иначе `HDR10|HDR+` → `HDR`.
7. `audioChannels` — `7.1` → `5.1` → `2.0`.
8. `audioTracks` — `dual audio` → 2, либо `N x audio|mvo|dvo|dub`.
9. **`extractStudios`** — студии перевода (см. §1.5).
10. **`parseYear`** — год (см. §1.6). При `profile.year === 'never'` шаг пропускается.
11. `subtitles`, `videoCodec`, `container`.
12. `compatibility` — риск для серверного GStreamer: `H.264`/`H.265` → `likely`; `XviD`, `DivX`,
    `MPEG-2`, `VC-1`, `WMV`, `RealVideo`, `H.263`, `AV1`, контейнеры `AVI/MPG/VOB/WMV/FLV/RM`,
    `DVDRip` без кодека, `RAW DVD` → `risky`.

### 1.3 `parseSignals` — нумерация, порядок попыток

Первое сработавшее правило из группы «с возвратом» останавливает разбор нумерации.

| # | Что ищет | Пример | Возврат |
|---|---|---|---|
| 0 | тип релиза | `[Фильм]`, `[П-ф]`, `Movie-`, `Gekijouban`, `[OVA]`, `[ТВ]` | нет, пишется в `releaseType` |
| 1 | диапазон сезонов + серий | `S1-5E1-62` | да |
| 2 | сезон + серия | `S02E07`, `S02E01-E10` | да |
| 3 | `NxNN` | `2x07` | да |
| 4 | cours аниме | `TV-2`, `ТВ-3` | нет, пишет сезон |
| 5 | финальный сезон | `The Final Season`, `Kanketsu-hen`, `последний сезон` | нет, пишет `finalSeason` |
| 6 | сезон словом | `Сезон: 3`, `3 сезон`, `3rd Season`, `[S01]` | нет |
| 7 | «вышло/всего» | `[16/16]`, `[50/50]` | да, серии 1..вышло |
| 8 | серии словом | `Серии: 1-12`, `12 серий из 24` | нет |
| 9 | диапазон «из» | `[1-12 из 24]`, `[1-12 из ??]` | нет |
| 10 | голый диапазон | `[1-19]` | нет |
| 11 | `E`-нотация | `E01-E12`, `E22` | нет |

Правило 9 принимает неизвестное общее число (`??`, `xxx`) — у онгоинга оно ещё не определено.

### 1.4 `extractVoiceTypes` — тип перевода

Множество, а не одно значение: раздача обычно несёт несколько переводов сразу.

1. Текстовые маркеры, все сразу: `дубляж|дублированный|dub` → **Дубляж**;
   `mvo|dvo|многоголос|двухголос` → **Многоголосый**; `avo|одноголос|авторский` → **Одноголосый**;
   `orig|ориг` → **Оригинал**.
2. Однобуквенные коды — только если `profile.voices !== 'text'`. Разбирается **поле целиком между
   вертикальными чертами**, состоящее только из кодов: `| D, P, L`. `D`→Дубляж, `P`→Многоголосый,
   `L`→Многоголосый, `L1`→Одноголосый, `A`→Одноголосый, `O`→Оригинал.
3. Если ничего не найдено и у профиля есть `voiceDefault` — берётся он.

`release.voiceType` — первое значение множества, для бейджей и старых фильтров.

### 1.5 `extractStudios` — студии перевода

Слоты выбираются профилем трекера (`studioSlots`), не словарём:

| слот | грамматика | пример |
|---|---|---|
| `parens` | `Nx MVO (Студия, Студия)` | `6 x MVO (LostFilm, HDrezka, TVShows)` |
| `brackets` | `[MVO\|Студия]` | `[Dub\|Red Head Sound]` |
| `from` | `от Студия` | `от Scarabey`, `от R.G. Механики` |
| `tail` | последнее поле после `\|` | `… WEB-DL 1080p \| Продубляж` |
| `none` | не искать — студия задана профилем | anidub, anilibria |

Порядок: слоты профиля → затем словарь известных студий (25 имён) по всему заголовку → сортировка по
позиции в строке → канонизация написания → если пусто и есть `studioDefault`, берётся он.

Канонизация схлопывает `HDRezka Studio` = `HDrezka`, `кубик в кубе` = `Кубик в Кубе`: сравнение идёт
по буквам и цифрам без регистра, с отбрасыванием родового хвоста `studio|студия|team|records`.
Отсеиваются языки и пометки: `Rus`, `Eng`, `Ukr`, `Sub`, `Original`, `Лицензия`, сами `MVO/DVO/AVO/Dub`.

**Словарь не является источником имён** — на корпусе структурный разбор находит 135 студий против 25
в списке. Роль словаря — канонизировать написание. Пополняется файлом, см. §8.

### 1.6 `parseYear` — год

1. **Поля-разделители**: содержимое `[...]` и `(...)` разбивается по запятым, плюс поля между `|`.
   Поле, целиком состоящее из года, даёт `confidence: 'high'`. Понимает `2024`, `2024 г.`,
   `2011-2019` (диапазон многолетнего пака).
2. **Запасной вариант**: год отдельным словом → `confidence: 'low'`.
3. Иначе `{ value: null, from: 'absent' }`.

Отрицательный просмотр вперёд отсекает `1920x1080`; трёхзначные и четырёхзначные не-годы (`2160p`,
`1080p`, `10-bit`) не подходят под `(19|20)\d{2}`. Названия-числа обходятся приоритетом
делимитированных полей: у `1917 (2019)` год — 2019.

### 1.7 Гейт по названию

1. `extractSearchTitleSegments(title, profile)`: применить `strip` профиля → разделить по `/` (и по
   `|`, если профиль не запрещает) → каждый сегмент очистить: снять ведущий `SxxExx`/`Exx`, обрезать
   по первой скобке, обрезать по техническому маркеру (`S01`, `1080p`, `WEB-DL`, `HEVC`, `Season 4`,
   `4 сезон`, `Серии:`) → **выбросить поля метаданных** по их собственному виду (коды перевода
   `D, P, L`, `4K`, `HDR`, год, названия источников).
2. Каждый сегмент сравнить со всеми известными названиями: локальное, `title`, оригинальное,
   английское, варианты из TMDB `alternative_titles`.
3. Совпадение: точное = 1.0; для письменностей без пробелов — вхождение подстроки от 3 символов;
   расширение (`название + добавка` в начале сегмента) = 0.6.
4. Порог 0.34. Ниже — `title-mismatch`.
5. `conflicting-title`: перед совпавшим сегментом стоит другой осмысленный заголовок **на том же
   языке**, что и совпавший сегмент, и что локализованное название цели.
6. `other-work-in-franchise`: сегмент точно совпал с названием соседней работы из TMDB-коллекции.

### 1.8 Выбор кандидатов из пула

Выполняется на каждый запрос к пулу (клик по серии, открытие пикера):

1. **Пользовательские фильтры** — `voice`, `translator`, `resolution`, `bitrate`. Сужающие: если
   фильтр оставляет ноль, применяется откат к предыдущему набору (в логе помечается `fallback`).
2. **Гейт идентичности** — `season-mismatch`, `episode-out-of-range`, `series-pack-for-movie`,
   `movie-release-for-episode`.
3. **Относительное сужение** — `title-extension` и `year-mismatch` отбрасывают кандидата, **только
   если в пуле есть точная замена**. Поэтому пул не может опустеть от этих правил.
4. **Ранжирование** — `quality + availability + matchConfidence − streamingRisk − pipeline`
   ([`torrent-mod-scoring-model.md`](torrent-mod-scoring-model.md)).

## 2. Реестр трекеров

### 2.1 Профили

Ключ — **id индексатора Jackett**, не отображаемое имя: имя пользователь переименовывает в UI Jackett.

| id | группа | разделители названий | год | перевод | слот студии | студия по умолч. | перевод по умолч. |
|---|---|---|---|---|---|---|---|
| `rutracker` | general | `/` и `\|` | делимитированный | только текст | `parens` | — | — |
| `tapochek` | general | `/` и `\|` | делимитированный | только текст | `brackets` | — | — |
| `exkinoray` | general | `/` и `\|` | делимитированный | только текст | любой | — | — |
| `rutor` | general | только `/` | делимитированный | коды и текст | `from` | — | — |
| `megapeer` | general | только `/` | делимитированный | коды и текст | `from` | — | — |
| `noname-club` | general | `/` и `\|` | делимитированный | коды и текст | `from` | — | — |
| `bigfangroup` | general | `/` и `\|` | делимитированный | коды и текст | `tail` | — | — |
| `anidub` | **anime** | только `/` | **нет** | коды и текст | не искать | `AniDUB` | Многоголосый |
| `anilibria` | **anime** | только `/` | **нет** | коды и текст | не искать | `AniLibria` | Многоголосый |
| *неизвестный* | general | `/` и `\|` | делимитированный | коды и текст | любой | — | — |

Группа `anime` определяет маршрутизацию: alias-запросы уходят адресно в неё, общий запрос — с её
исключением. Список группы не зашит в коде — он выводится из реестра.

### 2.2 Что срезается до разбора

| трекер | правило | зачем |
|---|---|---|
| `rutracker` | `[SERIAL]` в начале | префикс раздела, не часть названия |
| `exkinoray` | `- ExKinoRay` в конце | подпись трекера |
| `bigfangroup` | многоточие в конце | заголовки приходят обрезанными |
| `anidub` | `[RUS]` | маркер языка озвучки |
| `anilibria` | `E01-E12` перед названием, `- AniLiberty.TOP` | техническая приставка и подпись |

**Срез обязан возвращать на место захваченный разделитель.** Приставка `E01-E12` у AniLibria стоит
сразу после `/`, и шаблон захватывает разделитель ради контекста. Если вернуть вместо него пробел,
два названия склеиваются в один сегмент, склейка читается гейтом как «название плюс добавка» — и
раздача выбрасывается правилом `title-extension`, как только у общего трекера есть точное совпадение.
Так все раздачи аниме-трекеров молча пропадали из списка при наличии тех же раздач на rutracker.
Замыкает это тест «срез технической приставки не склеивает соседние названия».

### 2.3 Что реально извлекается — замеры

| трекер | n | год | перевод | студия | разрешение | источник | кодек | сезон | серия | тип релиза |
|---|---|---|---|---|---|---|---|---|---|---|
| rutracker | 397 | 98% | 47% | 33% | 46% | 66% | 5% | 45% | 47% | 23% |
| rutor | 339 | 99% | 48% | 42% | 61% | 91% | 26% | 55% | 6% | 1% |
| megapeer | 83 | 100% | 75% | 30% | 64% | 100% | 31% | 43% | 0% | 1% |
| noname-club | 304 | 100% | **2%** | 28% | 70% | 84% | 55% | 47% | 42% | 2% |
| bigfangroup | 172 | 88% | **2%** | 20% | 32% | 66% | 11% | 40% | 42% | 0% |
| tapochek | 167 | 95% | 53% | 36% | 78% | 91% | 5% | 47% | 50% | 25% |
| exkinoray | 107 | 100% | 70% | 34% | 50% | 95% | 32% | 25% | 30% | 0% |
| anidub | 28 | **0%** | 100% | 100% | 71% | 82% | 0% | 57% | 64% | 14% |
| anilibria | 183 | **0%** | 100% | 100% | 100% | 97% | 100% | 5% | 80% | 19% |

Нули и низкие значения, которые **не являются дефектом**:

- **год 0% у аниме-трекеров** — они его не пишут вовсе. Профиль объявляет `year: 'never'`, чтобы
  разбор не выдумывал год из случайных чисел.
- **перевод 2% у noname-club и bigfangroup** — эти трекеры действительно часто не указывают перевод;
  у bigfangroup хвост заголовка вдобавок обрезан многоточием.
- **сезон 5% у anilibria** — она публикует cours отдельными раздачами и сезон не нумерует. Отсутствие
  сезонного claim'а безопасно: такая раздача проходит сезонный гейт, а не отсекается.
- **серия 0-7% у rutor и megapeer** — они публикуют сезонные паки без диапазона серий.
- **кодек 5% у rutracker** — кодек указывают в теле раздачи, а не в заголовке.

## 3. Форматы по трекерам

### 3.1 rutracker

```
Дюна: Часть вторая / Dune: Part Two (Дени Вильнёв) [2024 г., фантастика, боевик, BDRemux 2160p] [4K|HDR] [DUB]
Игра в кальмара / Ojingeo geim / Squid Game / S3E1-6 of 6 (Хван Дон-хёк) [2025, Южная Корея, триллер, WEB-DL 2160p] 2x Dub + 5 x MVO (HDrezka Studio, LostFilm) + AVO (Ю. Сербин)
Королева слёз | Queen of Tears | Noonmului Yeowang (Ким Хи Вон) [16/16] [2024, Южная Корея, драма, HDTV] [субтитры]
```

Самая богатая грамматика. Названия через `/` **и** через `|` — оба варианта встречаются. Год внутри
квадратных скобок первым или после страны (`[Китай, 2019, …]` тоже встречается). Режиссёр в круглых
скобках. Студии — в скобках после типа перевода, списком. Азиатский контент часто размечен как
`[16/16]`.

Включаются: strip `[SERIAL]` → все правила нумерации → текстовые маркеры перевода (коды **не**
разбираются: `D` здесь встречается как часть текста) → слот студии `parens` → год делимитированный.

### 3.2 tapochek

```
Дюна: Пророчество / Dune: Prophecy / S1E6 of 6 (Анна Ферстер) [2024, США, фантастика, WEB-DL 1080p] [MVO|LostFilm]
Дюна: Часть вторая / Dune: Part Two (Дени Вильнёв) [2024 г., фантастика, BDRemux 2160p] [4K|HDR] [DUB]
```

Тот же род, что rutracker, но студия в квадратных скобках через черту: `[MVO|LostFilm]`,
`[Dub|Red Head Sound]`. Слот `brackets`.

### 3.3 exkinoray

```
Дюна: Часть вторая | Dune: Part Two | 2024 | BDRemux (1080p) | DUB, MVO, AVO - ExKinoRay
```

Всё через вертикальную черту, включая год отдельным полем. Подпись трекера в конце срезается. Типы
перевода перечислены словами — коды не нужны, но и не мешают.

### 3.4 rutor и megapeer

```
Дюна: Пророчество / Dune: Prophecy [S01] (2024) UHD WEB-DL 2160p | 4K | SDR | D, P, L
Дюна / Dune: Part One (2021) HDRip | D
Дюна: Часть вторая / Dune: Part Two (2024) BDRip 1080p от селезень | D
```

**Вертикальная черта здесь разделяет поля метаданных, а не названия** — поэтому профиль запрещает
делить по ней заголовок. Перевод записан однобуквенными кодами; без их разбора фильтр «Перевод» на
этих трекерах был бы слеп (было 1%, стало 48% и 75%). Студия — в слоте `от X`.

### 3.5 noname-club

```
Дюна / Dune: Part One (2021) BDRip [AV1/2160p] [4K, HDR10, 10-bit]
Долгая дорога в дюнах (1980-1981) WEBRip [H.264/1080p] (E1-7 of 7)
Super no Ura de Yani Suu Futari | Smoking Behind the Supermarket with You | История о перекуре за супермаркетом [2026, Web, 12] WebRip 1080p raw
```

Кодек и разрешение слитно через слэш внутри скобок — отсюда лучший показатель по кодеку (55%).
Серии в круглых скобках в конце. Черта используется **и** как разделитель названий (третий пример) —
поэтому профиль её разрешает, а поля метаданных отсеиваются по их собственному виду.

### 3.6 bigfangroup

```
Дюна: Пророчество / Dune: Prophecy, S1E1-6 of 6 (2024) WEB-DL 1080p | LostFilm …
```

Нумерация отделена запятой, а не слэшем. **Заголовки приходят обрезанными многоточием** — хвост со
студией часто теряется, отсюда 20% по студиям и 2% по переводу. Слот `tail` вытягивает то, что
уцелело.

### 3.7 anidub

```
Игра в кальмара / Squid Game E01-E06 [RUS] [HDTV 1080p]
Игра в кальмара S02 / Squid game S02 E01-E07 [RUS] [HDTV 1080p]
Атака титанов: финал - заключительная глава / Attack on Titan: The Final Season Part 3 [RUS] [HDTV 1080p]
```

Русское название, затем оригинал латиницей. `[RUS]` — маркер языка, срезается. Года нет никогда.
Студия — сам трекер. Сезон часто назван словом, а не номером.

### 3.8 anilibria

```
Игра лжецов / E01-E19 Liar Game - AniLiberty.TOP [WEB-DL 1080p][HEVC][1-19]
Твоё имя / Kimi no Na wa - AniLiberty.TOP [BDRip 1080p][HEVC][Фильм]
Баскетбол Куроко: Последняя игра / Kuroko no Basket- Last Game - AniLiberty.TOP [BDRip 1080p][AVC][П-ф]
```

Техническая приставка `E01-E19` стоит **перед** оригинальным названием — без её среза оригинал
теряется. Подпись `- AniLiberty.TOP` срезается. Разрешение и кодек размечены всегда (100%), года нет
никогда. Диапазон серий продублирован в хвосте в скобках. Полнометражки помечены `[Фильм]` или `[П-ф]`.

## 4. Фильмы

**Запрос.** Одна строка. Название берётся по настройке Lampa `parse_lang` (по умолчанию `df` —
оригинальное). Если полученное название не содержит ни латиницы, ни кириллицы — подставляется
локальное: на русских трекерах CJK-запрос возвращает случайную свежую выдачу, а не пустой ответ.

**Поле названия.** Для фильма приоритет `movie.title`, затем `movie.name`.

**Нумерация стирается.** Сезоны и серии для фильма не интерпретируются, но **разбираются**: сезонный
пак, попавший в поиск фильма, отклоняется кодом `series-pack-for-movie`. Одного `S1` для этого мало —
нужен второй сигнал (диапазон серий или слово «сезон»), иначе шум вроде `BDRip S1 5.1` отсекал бы
нормальные фильмы.

**Год — главный различитель.** Одноимённые фильмы разных лет (`Оно` 1990 и 2017, `Дюна` 1984 и 2021)
неразличимы ничем другим. Правило относительное: кандидат с несовпавшим годом отбрасывается, **только
если в пуле есть кандидат с точным попаданием в год цели**. Допуск ±1 год. Год с низкой уверенностью
(не из делимитированного поля) не отбраковывает.

**Соседние работы франшизы.** Из TMDB `belongs_to_collection` подтягиваются названия соседних частей
и работают негативными алиасами: `Дюна: Пророчество` под целью `Дюна` не проходит. Без коллекции
поведение прежнее — гейт соседей не выдумывает.

**Длительность.** `runtime` из TMDB. При отсутствии `payloadMbps` не считается вовсе, а не
подменяется средним значением.

## 5. Сериалы

**Поле названия.** Для сериала приоритет `movie.name`, затем `movie.title`. Порядок обратный
фильму намеренно: Lampa дописывает в карточку сериала `title` со значением-заглушкой
(«Фильм не найден»), а настоящее название держит в `name`.

**Пул на всё произведение.** Поиск идёт один раз по названию, без сезонного суффикса; смена сезона
фильтрует уже полученный пул. Сезонная дозагрузка запускается, только если завершившийся пул не
содержит ничего для выбранного сезона ([ADR-0005](../adr/0005-search-whole-season-once.md)).

**Сезон.** Явно названный сезон, не совпавший с целевым, — отказ `season-mismatch`. Релиз без
сезонного claim'а проходит: решать будут качество и доступность.

**Серия.** Целевая серия должна попадать в явный диапазон релиза, иначе `episode-out-of-range`.
Понимаются `S02E07`, `S02E01-E10`, `2x07`, `Серии: 1-12`, `[1-12 из 24]`, `[1-12 из ??]`, `E01-E12`,
`[16/16]`.

**Год сезона, а не премьеры.** Год цели для сериала берётся из `air_date` конкретного сезона; год в
заголовке сезонной раздачи — это год сезона. Гейт по году для сериалов **выключен**: у многолетних
паков (`Во все тяжкие (2008-2013)`) он вырезал бы именно то, ради чего построен единый пул.

**Онгоинги.** Пока произведение выходит, устоявшегося русского названия нет. Признак берётся из TMDB
`in_production`/`status`. Для онгоинга оригинальное название добавляется вторым запросом; варианты
названия из `alternative_titles` (страны RU/UA/BY/US/GB, до 12) участвуют и в запросе, и в гейте.

**Раскладка «Ромадзи / English / Локализованное»** не считается конфликтом заголовков: признак
настоящего конфликта (`Настоящая война / Игра престолов` — документальный фильм о сериале) в том, что
чужой заголовок написан на том же языке, что и совпавший сегмент, и что локализованное название цели.

## 6. Азиатская продукция

### 6.1 Семейства

Определяются из TMDB (`search/profile/work-profile.js`), а не из заголовка раздачи:

| признаки | семейство | следствия |
|---|---|---|
| анимация ∧ Япония | `anime` | alias-план, маршрут в аниме-трекеры, cours, сквозная нумерация |
| анимация ∧ Китай/Тайвань/Гонконг | `donghua` | то же, но другие алиасы |
| **не** анимация ∧ KR/JP/CN/TH/TW | `asian-live` | дорамы: запрос начинается с локального названия, аниме-трекеры **не** используются |
| анимация ∧ западный регион | `western-animation` | обычный сериальный профиль |
| остальное | `general` | общий путь |

Семейство `anime` действует и для фильмов: аниме-фильм получает alias-запросы и маршрут в
аниме-трекеры. Раньше он отсекался проверкой «только сериалы» и при отсутствии английского названия
оставался вообще без запросов.

### 6.2 Дорамы и китайское игровое кино

Ключевая особенность — **запрос**. Оригинальное написание (`눈물의 여왕`, `陈情令`) на русских трекерах
не находит ничего: трекер отдаёт случайную свежую выдачу, гейт её отбрасывает, и это выглядит как
«раздач нет». Поэтому для `asian-live` запрос начинается с локального названия, затем английское.

Нотация серий — `[16/16]`, `[30/30]`, `[50/50]` («вышло/всего»), читается как серии 1..вышло.
Аниме-трекеры для дорам не используются: их там нет.

Порядок полей в скобках может быть любым: и `[2019, Китай, …]`, и `[Китай, 2019, …]`.

### 6.3 Cours и нумерация аниме

**Сезон словом.** `3rd Season`, `2nd Season` дают номер сразу. `The Final Season`,
`Kanketsu-hen`, `последний сезон` дают только признак `finalSeason`: какой это сезон по счёту,
заголовок не знает. Признак сопоставляется с последним сезоном по TMDB; если сезоны неизвестны,
отказывать не за что.

**Cours как сезоны.** `TV-1`, `ТВ-2` распознаются как номера сезонов. Голый `[TV]` — только тип
релиза и сезонного сигнала не создаёт.

**Сквозная нумерация.** Релиз `E27-E39` без указания сезона — это серии второго сезона в сквозном
счёте. Сумма серий предыдущих сезонов из TMDB даёт сквозной номер. Она врёт на спецвыпусках и
рекапах, поэтому сквозной номер может только **принять** кандидата и никогда не служит основанием
для отказа; если сезон в релизе назван явно, сквозной номер не рассматривается вовсе.

### 6.4 Тип релиза

Аниме-трекеры помечают его отдельно от нумерации:

| маркер | тип | пример |
|---|---|---|
| `[Фильм]`, `[Movie]`, `[П-ф]`, `Movie-`, `Gekijouban` | `movie` | `Твоё имя / Kimi no Na wa [HEVC][Фильм]` |
| `[OVA]`, `[ONA]` | `ova` | |
| `[Спешл]`, `[Special]` | `special` | |
| `[TV]`, `[ТВ]` | `tv` | `Аниме [TV] [1-12 из 12]` |

Полнометражка не может быть кандидатом на **конкретную серию** сериала (`movie-release-for-episode`),
но остаётся в общем пуле произведения. Без этого признака она была неотличима от серии, у которой
просто не разобрался номер.

На корпусе: 103 полнометражки, 61 `tv`, 13 `ova`, 4 спешла.

### 6.5 Перевод на аниме-трекерах

anidub и anilibria не пишут тип перевода словами **ни разу** на 211 живых заголовках. Профиль трекера
объявляет его сам (`voiceDefault: 'Многоголосый'`) — иначе фильтр «Перевод» на этих трекерах не
неполон, а слеп. Явно названный в заголовке перевод сильнее умолчания.

### 6.6 CJK в названиях

Нормализация сохраняет диапазоны хираганы, катаканы, кандзи и хангыля. Для письменностей без пробелов
сравнение идёт по вхождению подстроки — но не короче 3 символов, иначе совпадает почти всё.
Ключ дедупликации запросов — `normalizedTitleKey` (CJK сохраняет), а не `compact` (CJK вырезает
целиком и превращал единственное название в пустой список запросов).

## 8. Как добавить или поправить трекер без пересборки

`%LocalAppData%\TorrServer\data\search-rules.json`, отдаётся плагину через
`GET /api/search-rules`. Читается по времени изменения — перезапуск менеджера не нужен.

```json
{
  "studios": [
    { "name": "DubLikTV", "aliases": ["DubLik TV", "ДабЛикТВ"] },
    { "name": "ProFilms", "disabled": true }
  ],
  "trackers": [
    { "id": "новый-аниме-трекер", "group": "anime", "studioDefault": "NewFansub" },
    { "id": "noname-club", "studioSlots": "tail" }
  ]
}
```

Поля трекера: `group`, `titleSeparators`, `year`, `voices`, `studioSlots`, `studioDefault`,
`voiceDefault`, `strip` (строками, не регэкспами — правка данных не должна ронять разбор).
Незаполненные поля не сбрасывают встроенные значения. Незнакомая версия схемы игнорируется целиком,
битый JSON отдаёт пустые правила и предупреждение — поиск при этом продолжает работать на
встроенных значениях.

Неизвестный индексатор Jackett получает общий профиль и не требует правок вовсе.
