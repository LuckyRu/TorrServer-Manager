# ADR-0004: Тулбар — настоящий `Lampa.Filter`, без отдельного поля поиска

**Статус:** Принято
**Дата:** 2026-08-06

## Контекст

Первая версия тулбара Torrent Mod строила чипы вручную: `.simple-button.simple-button--filter` divs для
поиска (`Lampa.Input.edit` — голое текстовое поле), сезона, перевода и качества. Внешне похоже на нативный
`.torrent-filter`, но по факту — реимплементация без общей логики Lampa.

Прямая критика (сессия 2026-08-06): «Ты вообще видел фильтр именно в онлайн моде? Опять что-то своё
придумал вместо фильтра от лампы?» и «Где системный интерфейс поиска по названию?». Проверка вживую (не
угадывание) показала: `new Lampa.Filter(object)` — реальный класс, чей `.filter--search` открывает
нативный пикер «Уточнить» — свой ввод (через настоящий виджет `SearchInput`, с сохранением истории в
`Storage['user_clarifys']`), «Глобальный поиск», альтернативные названия из TMDB
(`movie.names`/`movie.alternative_titles`), комбинации название+год из `search_one`/`search_two`.
Ничего из этого не воспроизвести самодельной разметкой — оно живёт только внутри `Lampa.Filter`.

Дальше — сверка с реальным использованием у Online Mod (`new Lampa.Filter(object)`,
`filter.set('sort', его список балансеров)`, `filter.set('filter', его список качества)`) показала: Online
Mod тоже не добавляет своих чипов, а переиспользует ровно два дополнительных слота Filter'а — `sort` и
`filter` — под свои, никак не связанные с буквальным смыслом чипов концепции.

## Решение

Тулбар строится через `new Lampa.Filter({movie})`. Поисковый слот намеренно не передаётся: произведение уже
выбрано через TMDB, а Torrent Mod не поддерживает ручную замену поискового запроса. Сезон живёт в слоте
`sort` (`filter.set('sort', buildSeasonItems(...))`), Перевод+Качество — в `filter` как вложенное меню
(`filter.set('filter', [{title:'Перевод', items:[...]}, {title:'Качество', items:[...]}])`). Разметка
и логика взаимодействия — от Lampa; структура данных (что именно фильтруем) и callback `filter.onSelect` —
наши. Изменение параметров поиска пользователем не предусмотрено: если TMDB не дала подходящий контекст,
плагин не предлагает ручной обход этого ограничения.

## Рассмотренные варианты

- **Настоящий `Lampa.Filter`, слоты `sort`/`filter` переиспользованы (выбран)** — минимум кода, максимум
  нативности, подтверждённый Online Mod паттерн.
- **Сохранять поисковый слот Lampa** — отвергнуто: Torrent Mod получает произведение из TMDB и сам
  строит запросы к индексаторам; второй путь для ручной смены названия создавал неподдерживаемое
  расхождение между карточкой TMDB и доменным контекстом поиска.
- **Своя разметка чипов** — отвергнута: не нужна для оставшихся штатных `sort`/`filter`-слотов и
  возвращает ответственность за навигацию в код плагина.

## Последствия

- Пользователь получает штатные фильтры сезона, перевода и качества без дублирования поискового UI.
- **Побочно найден серьёзный баг, не специфичный для этого решения**: `Lampa.Select.show().close()` сам
  не восстанавливает активный `Controller` — это забота вызывающего кода через `onBack`. Не будь этой
  миграции, баг остался бы незамеченным дольше. См.
  [`system-design/lampa-navigation-contract.md`](../system-design/lampa-navigation-contract.md).
- Подписи чипов («Сортировать»/«Фильтр») — родные, не переименовываются публичным API; семантическое
  несоответствие («Сортировать» значит «Сезон») смягчается тем, что в Online Mod то же самое.
