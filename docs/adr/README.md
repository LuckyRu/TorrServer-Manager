# Architecture Decision Records

Короткие протоколы решений: контекст → что выбрали → что отвергли и почему → последствия.

**Правило: ADR не редактируются задним числом, кроме опечаток.** Если решение позже отменили или
заменили — пишется новый ADR, а в статусе старого меняется `Принято` на `Заменено → ADR-000N` со ссылкой.
История решений должна остаться читаемой: почему тогда казалось правильным то, что сейчас не так.

Новый ADR — копия [`template.md`](template.md), следующий свободный номер, кебаб-заголовок.
