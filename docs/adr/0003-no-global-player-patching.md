# ADR-0003: Torrent Mod не патчит `Lampa.Player`/`Lampa.Torserver` глобально

**Статус:** Принято
**Дата:** 2026-08-05, буферизация реализована 2026-08-06

## Контекст

`SmartTsPlugin.js` уже глобально оборачивает `Lampa.Torserver.stream` / `Lampa.Player.play` /
`Lampa.Player.playlist` / `Lampa.Player.callback` / `Lampa.Player.stat`, чтобы получить контроль над
воспроизведением и показать собственную предзагрузку. Torrent Mod по архитектуре (ADR-0001) — второй,
независимый торрент-плагин, активный одновременно со Smart TS по умолчанию (на момент решения; Smart TS
позже убран, см. `CLAUDE.md`).

Нужен был способ показать собственную буферизацию **под длительность воспроизведения**, а не под
фиксированный размер/таймаут, для раздачи, которую выбрал сам Torrent Mod.

## Решение

Не патчить `Lampa.Player`/`Lampa.Torserver` глобально. Вместо этого:

1. Инфохеш раздачи уже известен — извлекается прямо из её собственного magnet URI
   (`xt=urn:btih:HASH`), перехватывать ничего не нужно.
2. `Lampa.Torrent.start(...)` вызывается как обычно — это то, что реально регистрирует magnet в
   TorrServer и запускает нативный список файлов.
3. Свой прогресс — независимый поллинг `TorrServer /cache` по уже известному хешу, с целью
   `targetBytes = bitrateMbps × leadSeconds` (буфер на ~25 сек воспроизведения при оценённом битрейте
   этой раздачи), а не фиксированный МБ/таймаут.
4. Выбор нужного файла в списке — не патч, а **слушатель** `Lampa.Listener.follow('torrent_file', ...)`
   (то же событие, на которое и так подписан Smart TS) — слушать безопасно и композируемо, в отличие от
   патчинга разделяемой функции.

## Рассмотренные варианты

- **Не патчить, слушать события + поллинг (выбран)**.
- **Патчить `Lampa.Player.play` как Smart TS** — отвергнут: оба плагина включены одновременно по
  умолчанию, двойной патч одних и тех же глобальных функций двумя независимыми плагинами — надёжный
  источник трудноуловимых багов порядка оборачивания/отключения.

## Последствия

- Собственная буферизация полностью независима от того, включён ли Smart TS одновременно — нет гонки
  между двумя оверлеями.
- Экран `torrent-mod-preload` — полноэкранный оверлей поверх нативного диалога `Lampa.Torrent.start`
  (не отменяет его, просто визуально перекрывает; нативный диалог продолжает нужную работу — регистрацию
  торрента и список файлов — под капотом).
- Требует собственной логики отмены/таймаута/явного предупреждения о риске затыка (скорость закачки
  устойчиво ниже битрейта) — детали в
  [`system-design/torrent-mod-search-pipeline.md`](../system-design/torrent-mod-search-pipeline.md).
