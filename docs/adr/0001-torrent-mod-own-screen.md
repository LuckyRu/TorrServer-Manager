# ADR-0001: Torrent Mod — свой экран, а не обёртка над нативным

**Статус:** Принято
**Дата:** 2026-08-05

## Контекст

В проекте уже был `SmartTsPlugin.js` — плагин, который добавляет сезон/серии и предзагрузку поверх
нативного торрент-экрана Lampa, глобально патча `Lampa.Player.play`/`Lampa.Torserver.stream`. Поиск у
него — один индексатор Jackett (RuTracker) через `/api/smart-search`, результатов своих не показывает:
либо `Lampa.Select.show` оверлей, либо нативный экран `torrents`, если выбор неоднозначен.

Нужен был второй плагин — агрегированный поиск сразу по всем источникам Jackett (эндпоинт
`indexers/all/results` уже отдаёт нужный формат — проверено вживую на локальном Jackett, 5 индексаторов,
без парсинга Torznab XML). Встал вопрос архитектуры: встраиваться в существующие нативные экраны
(как делает сторонний плагин Online Mod для онлайн-просмотра — не рисует свой экран результатов, просто
добавляет источники в Settings + Select-пикер на карточке) или строить собственный экран результатов.

## Решение

Отдельный самостоятельный плагин `TorrentModPlugin.js` со своим экраном результатов
(`Lampa.Component.add('torrent_mod', ...)`), своей кнопкой на карточке, независимый от
`SmartTsPlugin.js`.

## Рассмотренные варианты

- **Свой экран (выбран)** — полный контроль над сортировкой/фильтрами/индикацией загрузки на уровне
  качества нативного торрент-компонента (сиды/пиры/размер/качество, прогресс в процентах и скорости).
  Цена — весь Controller/Activity/Explorer контракт экрана нужно реализовать самим, правильно (см.
  [`system-design/lampa-navigation-contract.md`](../system-design/lampa-navigation-contract.md) — это
  далось не бесплатно, была серия навигационных багов).
- **Встраивание в нативные экраны (как Online Mod)** — отвергнут: агрегированный список источников с
  собственной сортировкой/фильтрами по качеству плохо ложится на нативный `torrents`-компонент, который
  не спроектирован под богатую пользовательскую сортировку смешанных результатов разных индексаторов.

## Последствия

- Полная свобода в UI/UX результатов (сезон-первичен-а-торрент-вторичен, единый скоринг, буферизация под
  длительность) — то, чего нативный экран не даёт.
- Вся ответственность за навигацию (Controller/Activity wiring) — на нас; нативные экраны это получают
  бесплатно от фреймворка. Отсюда серия находок в
  [`system-design/lampa-navigation-contract.md`](../system-design/lampa-navigation-contract.md).
- Два независимых торрент-плагина одновременно активными по умолчанию первое время (`SmartTsPlugin.js` +
  `TorrentModPlugin.js`) — источник решения ADR-0003 (не патчить глобально). `SmartTsPlugin.js` в итоге
  убран (см. историю в `BuiltInPlugins.cs` и `CLAUDE.md`) — Torrent Mod вырос в полноценную замену.
