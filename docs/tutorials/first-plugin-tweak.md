# Первая правка: изменить текст в Torrent Mod и увидеть результат без пересборки

Учебное упражнение — цель не решить реальную задачу, а на практике пройти цикл, которым дальше
пользуешься для всего: живая проверка поведения Lampa → правка JS → мгновенная проверка без пересборки
`.exe`. К концу — работающий локальный dev-цикл и intuition, как перепроверять, что правка реально
дошла до приложения.

## Предпосылки

- Репозиторий склонирован, `dotnet build TorrServerManager.csproj` проходит чисто.
- `TorrServerManager.exe` уже когда-то был опубликован и запущен (см.
  [`how-to/release-a-change.md`](../how-to/release-a-change.md), если ещё ни разу не собирался) — Plugin
  Hub должен отвечать на `http://127.0.0.1:8095/`.

## Шаг 1 — найти, что менять

Открой `TorrentModPlugin.js`, найди строку с текстом кнопки на карточке:

```js
'<span>Torrent Mod</span>'
```

(в функции `addCardButton`, секция `// ---------- card button ----------`).

## Шаг 2 — поменять текст

Замени на что угодно заметное, например `'<span>Torrent Mod (тест)</span>'`. Сохрани файл.

## Шаг 3 — проверить синтаксис

```bash
node --check TorrentModPlugin.js
```
Если тихо — синтаксис в порядке. Дешёвая проверка перед деплоем: `Lampa.Component.create` молча
подменяет любой компонент с ошибкой в конструкторе на пустой экран, без видимой ошибки — лучше поймать
опечатку тут, чем потом гадать, почему что-то не отрисовалось.

## Шаг 4 — задеплоить без пересборки `.exe`

```bash
cp TorrentModPlugin.js "$LOCALAPPDATA/TorrServer/dev-plugins/TorrentModPlugin.js"
curl -s -X POST http://127.0.0.1:8095/api/plugins/refresh -d ""
```
(`-d ""` обязателен — без тела `HttpListener` вернёт 411.)

## Шаг 5 — увидеть результат

Открой `http://127.0.0.1:8095/app/` в браузере, найди любую карточку фильма/сериала, открой её. Кнопка
на карточке должна показывать новый текст.

Если не показывает — проверь вживую, что именно отдаёт Plugin Hub, не гадай:
```bash
curl -s http://127.0.0.1:8095/api/config | grep -A2 torrent_mod
```
Смотри `cacheError` у записи `torrent_mod` — если не пусто, `/api/plugins/refresh` на шаге 4 не прошёл
успешно, и стоит перечитать его вывод.
